# Contributing

We are open to, and grateful for, any contributions made by the community.

By contributing to **react-flow-ui-engine**, you agree to abide by the [Code of Conduct](./CODE_OF_CONDUCT.md).

---

## Reporting Issues and Asking Questions

Before opening an issue, please search the issue tracker:

https://github.com/react-flow-ui-engine/react-flow-ui-engine/issues

to make sure your issue hasn't already been reported.

---

### Bugs and Improvements

We use the issue tracker to keep track of:

- bugs
- feature requests
- documentation improvements
- architecture discussions

---

### Getting Help

For usage questions:

- Provide minimal reproducible example
- Include flow definition
- Mention package versions

---

## Development

```bash
git clone https://github.com/your-username/react-flow-ui-engine.git
cd react-flow-ui-engine
pnpm install
```

---

### Running Examples

```bash
pnpm dev
pnpm dev:onboarding
```

---

### Building

```bash
pnpm build
```

---

### Type Checking

```bash
pnpm typecheck
pnpm check:examples
```

---

## Sending a Pull Request

1. Fork the repo
2. Create a branch
3. Make changes
4. Run checks
5. Submit PR

---

### Changesets

```bash
pnpm changeset
```
