# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our pledge

We are committed to making participation in this project a harassment-free experience for everyone.

## Expected behavior

- Be respectful and constructive.
- Assume good intent.
- Focus feedback on ideas and implementation details.
- Help make the project welcoming for new contributors.

## Unacceptable behavior

Harassment, personal attacks, discriminatory language, and sustained disruption are not acceptable.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, issues, and pull requests that are not aligned with this Code of Conduct.
